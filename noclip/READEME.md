Noclip (kavy.noclip)

Toggleable noclip for Geometry Dash. Default toggle key: 6 (rebind it in the mod's settings).

Build the .geode

Push this folder to a GitHub repo. The included workflow builds every platform and
uploads kavy.noclip.geode as the "Build Output" artifact.

Local build (needs the Geode SDK + CLI): geode build
